# 余烬行旅

安装依赖：`npm install`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose -p pinru-jdk003-high-1113 up --build -d`，访问 http://localhost:18023。

停止：`docker compose -p pinru-jdk003-high-1113 down`。

## 三敌人阵形（遭遇规则）

- 每场遭遇最多三名敌人，分为**前排 / 后排 / 召唤物**，每名敌人拥有稳定身份 id，
  与数组位置无关；前排倒下后后排补位，但已入队的单体效果仍按 id 打原目标，不会转火。
- 攻击牌先选合法目标（优先前排，其次后排，最后才是召唤物），UI 会高亮当前合法目标。
- 效果范围：
  - `single` 单体：入队时锁定目标 id，目标提前死亡则该效果取消；
  - `pierce` 穿透：单体且无视格挡；
  - `aoe` 群攻：对所有存活敌人分别生效，单个目标死亡不影响其余目标。
  - 中毒按相同范围规则进入效果队列。
- 每名敌人的意图、格挡、力量/中毒/荆棘分别计算与展示。
- **召唤物死亡不算遭遇胜利**；只有全部“需要击败的敌人”（前/后排）倒下才判胜。
- 反伤（荆棘）导致旅人与最后一名敌人同归于尽时，旅人死亡优先，仍判失败。
- 掉落按敌人身份逐笔计入 `collectedGold`，胜利后聚合成一次奖励结算；
  存档恢复会保留阵形、队列中待处理目标身份与已经计入的掉落。
- 旧版单敌人存档在读取时自动迁移为单人阵形，可继续游戏。
